## Scaffold

Before starting work that cannot be completed reliably in one sitting —
multi-session scope, or verification infrastructure that must outlive any
single context — use the `scaffold` skill to turn confirmed requirements
into an approved plan, a machine-checked ledger, and a bounded unattended
run. Execute a well-understood single-context task directly instead; never
decide by predicting duration.

Scaffold artifacts live in `.scaffolding/` (hidden, untracked via
`.git/info/exclude`, self-versioned). Product code, docs, and commit
messages carry no scaffold vocabulary.
